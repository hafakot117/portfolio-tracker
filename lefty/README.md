# Switch Hands

A small educational website for adults curious about training their non-dominant
(left) hand.

Includes:
- 18+ age gate with required disclaimer acknowledgement
- Brain-science explanation (contralateral motor control, corpus callosum,
  neuroplasticity, etc.) with an interactive SVG diagram
- Pros &amp; cons of training the non-dominant hand
- 30-day challenge tracker (progress saved in `localStorage`)
- Four mini-games: mirror drawing, click targets, reaction time, left-hand typing
- Full legal disclaimer

Pure static HTML/CSS/JS &mdash; deployable directly via GitHub Pages.

## Run locally

Just open `index.html` in a browser, or serve the folder with any static server:

```sh
python3 -m http.server -d lefty 8000
```

Then visit http://localhost:8000.
